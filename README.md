# 🔥 自律打卡

一个纯前端、零依赖的自律习惯打卡 PWA 应用，支持安装到电脑 / 手机桌面，离线可用。

## 功能

- **三类任务按需选择**：**定性打卡**（完成即勾选，如背单词）、**定量目标**（达到目标数值才算完成，如走 6000 步）、可选**时间段**（开始–结束时间，像日历事件一样显示）和**地点**
- **点击即改**：在今日清单里直接点击任务名称即可打开编辑弹窗，目标值、时间、地点随时可改
- **专注计时器**：每个任务带 ▶ 专注按钮，点击后后台计时（切去别的软件干活计时照走），⏹ 结束自动记录当天用时，时间轴显示「⏱ 用时 X 分钟」；同一时间只专注一件事，开启新的会自动结算上一个；**定量任务单位设为「分钟」时，专注时长自动换算成任务进度**
- **关联链接**：任务可绑定一个链接（https 或 obsidian://、vscode:// 等协议），清单里点 🔗 一键打开相关资源；纯本地文件路径会自动复制（浏览器安全限制无法直接启动本地软件）
- **中长期计划**：设定带截止日期的目标，拆成一串有序子任务，逐个打勾推进；支持多个计划并行，当前目标完成后**自动跳到下一个目标**，全部完成有提示。可随时添加子任务、编辑或删除
- **今日清单**：与计划并排，有时间段的任务按开始时间排序并显示 ⏰ 徽章；点击左侧圆圈打勾标记完成，完成后自动画横线；数值类任务点击右侧进度徽章展开 ＋/− 或直接输入记录进度，**达标自动完成打卡**；点击任务名称可直接编辑
- **习惯管理**：今日清单标题栏的 ⚙ 按钮打开习惯管理窗口，所有每日习惯集中一处：查看类型/目标/时间/地点概要，以及**执行分数（完成天数/计划天数 + 百分比）**；✏️ 编辑、🗑️ 删除、＋ 新习惯；**⏸ 一键暂停**——不想做的事点了就暂停，不出现在清单、不计入完成率和执行分数，▶️ 一键恢复
- **迷你日历 + 时间轴**：位于今日清单右侧，每天显示当日完成率，点击任意日期，下方时间轴按时间顺序展示当天每项任务的安排、完成状态与打卡时间；月份可前后切换；**未完成计划的截止日期会标灰色 ★**（悬停看详情）
- **自动统计**：连续打卡天数、当日完成项数、累计完成次数、热力图附全勤天数 / 平均完成率 / 最长连续天数
- **近一年热力图**：GitHub 风格的热力图，滚动显示从今天往前一年的数据（右端始终是本周），颜色 = 当天任务完成率- **任务管理**：新建 / 编辑 / 删除任务（删除后历史记录保留），自定义图标、目标值、单位
- **打卡动画**：打勾时圆圈弹跳、对勾弹入、星星迸发；当日任务全部完成还有全屏庆祝提示
- **☁️ 坚果云同步（电脑端）**：设置里授权一次坚果云同步文件夹，之后每次打卡自动把备份写入其中（坚果云客户端自动上传云端）；换设备点「立即同步」会**智能合并**两边的任务/计划/记录（按修改时间取新，不丢数据）。手机端浏览器无文件夹权限，用导出/导入 + 坚果云 App 中转
- **其他**：明暗主题切换、数据导出 / 导入 JSON 备份、PWA 离线使用

## 安装到设备（PWA）

PWA 需要通过 **HTTPS 网址** 安装（见下方「部署」），安装后就是桌面 / 主屏幕上的独立应用，带图标、全屏窗口、断网可用。

- **Windows**：用 Edge 或 Chrome 打开网址 → 地址栏右侧出现「安装」图标（或菜单 → 应用 → 将此站点作为应用安装）→ 确认后出现在开始菜单和桌面
- **Android**：用 Chrome 打开网址 → 菜单 → 「添加到主屏幕」/「安装应用」
- **iOS**：用 Safari 打开网址 → 分享按钮 → 「添加到主屏幕」

## 部署（一次性，5 分钟）

把本目录的 5 个文件（`index.html`、`manifest.json`、`sw.js`、`icon-192.png`、`icon-512.png`）放到任意静态网站托管即可，推荐 GitHub Pages：

1. 在 GitHub 新建一个仓库（如 `self-discipline`），把这 5 个文件传上去
2. 仓库 → Settings → Pages → Source 选 `main` 分支 → Save
3. 一分钟后访问 `https://<你的用户名>.github.io/self-discipline/`，在电脑和手机上都用这个网址打开并安装

其他任何支持静态文件的 HTTPS 托管（Cloudflare Pages、Gitee Pages、自己的服务器等）都适用。

> 直接双击 `index.html`（file:// 方式）也能正常使用全部功能，只是浏览器限制导致无法安装为 PWA、无法离线缓存。注意：file:// 和 https 两种方式的 localStorage 数据互不相通，建议固定用部署后的网址。

## 数据说明

- 所有数据保存在**当前设备的浏览器 localStorage** 中，不上传服务器
- 换设备 / 换浏览器 / 清除浏览器数据前，先在「⚙️ 设置 → 导出备份」导出 JSON，到新设备上「导入备份」
- 应用更新方式：部署的文件替换后刷新页面即可生效（页面本身总是加载最新版）；若改动了 `manifest.json` 或图标，需把 `sw.js` 里的 `CACHE` 版本号加一

## 后续规划

- **多设备云同步**：坚果云 WebDAV 不允许浏览器跨域直连（无 CORS 响应头），如需同步建议接 Supabase 等云数据库（已验证本机连通性良好），按「合并策略」同步各设备的任务与打卡记录

## 首次使用

应用内置三个示例任务（背单词、看一篇论文、走路），可直接打卡试玩；「⚙️ 设置 → 清空全部数据」可重置为示例状态。
